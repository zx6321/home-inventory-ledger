# 家物簿 v6

本地优先的家庭物品生命周期、消费控制与习惯打卡 PWA。

## 已实现

- 家庭物品仪表盘
- 物品新增、编辑、删除、照片、自定义分类、位置、价格、有效期与保修期
- 分类支持新增、重命名和删除，旧分类及物品会自动兼容
- 使用日期用于计算持有天数与日均成本
- 持有天数和日均成本自动计算
- 首页电子产品持有天数与日均成本明细
- 衣物数量、细分品类统计及分类直达
- 首页日历多条备忘，可按日期直接新增和删除
- 大类支持图片卡片与紧凑文字两种视图
- 按大类显示专属字段：细分品类、使用状态、适合季节、单位、购买途径等
- 每个专属字段的选项均可新增、改名和删除，已有物品自动兼容
- 全部物品支持勾选、全选当前结果和批量删除
- 首页按“日历—大类/衣物—电子产品”的阅读顺序排版
- 分类和衣物细分支持淡入进入、返回及原滚动位置恢复
- 浏览器返回与移动端返回手势可回到之前的总览位置
- 管理分类内可进入每个一级分类的二类项目管理
- 电子产品支持按持有天数、日均成本升序或降序排列
- 全部物品支持按细分品类、使用状态、季节、单位和购买途径筛选
- 全部物品支持紧凑列表和宽松图片两种展示
- 首页移除统计卡和最近更新，快速记录与年度挑战整合到左侧
- 电子产品查看区加高，可一次浏览更多记录
- 分类分布、购入总额、到期提醒
- “不消费的一年”等自定义挑战及月历打卡
- 搜索和分类筛选
- IndexedDB 本地保存
- 完整 JSON 备份与恢复
- PWA 离线缓存和手机安装

私人数据只保存在当前浏览器，不会上传到托管服务器。
